 Go 并发 SSH 批量巡检工具


这个项目是干嘛的？
用代码代替手动，在一台电脑上同时控制多台Linux服务器执行命令，并把结果收集起来。
功能


1.读取配置文件
程序会读取hosts.txt，（可自动处理文件的空行和空格，进行数据清洗）把IP提取出来（需提前将服务器IP放进hosts.txt文件）


2.批量并发连接
用go的goroutine让多台机器同时开始连接和执行命令。
细节：用了channel来收集每台机器执行完的结果。


3.并发限制
虽然能并发，但是设置了上限
细节：用Channel做了一个“信号量”，连完一台才释放名额去连下一台，防止瞬间开启太多连接把电脑网卡或者目标服务器防火墙搞崩


4.超时熔断（防卡死）
如果某台机器网络很差，或者执行的命令卡住了，程序不会一直等
细节:用Context设了3秒超时，时间到了，直接强制杀死超时机器的进程，继续处理其他机器保证了整体任务不会卡死


5.日志和报告生成（保留数据）
运行过程中状态会打印在屏幕上，跑完会在本地生成一个report.json文件
细节：屏幕日志使用了slog，带时间戳。生成的JSON文件里记录了每台机器执行成功还是失败、花了多长时间、输出了什么。


安全提示：代码中目前使用了ssh.InsecureIgnoreHostKey()忽略了主机密钥校验，为了方便本地开发测试。在真实的生产环境中，建议替换为严格的known_hosts校验，以防中间人攻击。
